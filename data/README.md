# Corpora

## Modern English

[TinyStories](https://huggingface.co/datasets/roneneldan/TinyStories) contains
synthetic children's stories generated by GPT-3.5 and GPT-4 in simple modern
English. It is narrative prose, not a modern translation of Shakespeare or
an instruction-following corpus. See the [authors' paper](https://arxiv.org/abs/2305.07759).

```sh
python -m llm.prepare --corpus tinystories
python -m llm.train --data data/tinystories.txt --validation-data data/tinystories-valid.txt --out checkpoints/tinystories.pt
```

Preparation takes the first 10,000 complete stories from the official training
file and 1,000 from the official validation file. It closes each download after
the subset, rather than downloading the entire multi-gigabyte dataset. Select
larger subsets with `--stories` and `--validation-stories`. Story endings are
preserved as `<|endoftext|>` and become one special BPE token.

- `tinystories.txt`: training subset.
- `tinystories-valid.txt`: official validation subset.
- `tinystories.json`: source URLs, subset counts, and provenance.

The dataset card specifies CDLA-Sharing-1.0. Source files are
[TinyStories-train.txt](https://huggingface.co/datasets/roneneldan/TinyStories/blob/main/TinyStories-train.txt)
and [TinyStories-valid.txt](https://huggingface.co/datasets/roneneldan/TinyStories/blob/main/TinyStories-valid.txt).

## Shakespeare

The default training corpus is Project Gutenberg ebook 100,
[The Complete Works of William Shakespeare](https://www.gutenberg.org/ebooks/100).
This is the complete collection in that edition, not the tiny Shakespeare excerpt.

Run `python -m llm.prepare` to download the UTF-8 edition. Preparation removes
the Gutenberg header and footer and normalizes line endings. Titles, the table
of contents, stage directions, punctuation, and verse line breaks are retained.
The original download, including the Gutenberg license, is saved alongside it.

- `shakespeare.txt`: cleaned training corpus.
- `shakespeare-source.txt`: original ebook, attribution, and license.

These generated files are ignored by Git. To prepare an offline copy, use
`python -m llm.prepare --source /path/to/100.txt`.
